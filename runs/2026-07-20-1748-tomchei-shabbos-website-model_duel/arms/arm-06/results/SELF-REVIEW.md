| SR-01 | major | `lib/media/storage.ts:61` (`copyObject`) vs `app/uploads/[name]/route.ts:24` | Season-wizard catalog copies 404 under the local media driver. `copyObject` stores bytes as `copy-<uuid>-<original storedName>`, but the `/uploads/[name]` route only serves names matching `^[0-9a-f-]{36}\.(jpg|png|webp|gif)$`. Copied names fail the pattern, so every copied product photo is broken whenever `BLOB_READ_WRITE_TOKEN` is unset (local + test deployments). Eight `copy-*-p10-wizard-*.png` files in `.uploads/` prove this path ran in this tree. | Either name copies `<uuid>.<ext>` like originals, or extend the serve pattern to also accept `^copy-[0-9a-f-]{36}-[0-9a-f-]{36}\.(jpg|png|webp|gif)$` (still anchored, no traversal). Add a smoke assertion that a copied asset URL returns 200 under the local driver. |
| SR-02 | major | `lib/payments/stripe.ts:99` (idempotency key), reached from `lib/checkout/pay.ts:27` | A customer who edits a draft after a pay attempt cannot pay again for up to 24h. Every `createCheckoutSession` call for an order reuses idempotency key `checkout-<orderId>`; after an edit + re-submit the frozen total changes, and Stripe rejects a reused key carrying different parameters (400 idempotency error), which propagates as an unmapped 500. Same-key replay can also hand back a cached, near-expired hosted session URL. Realistic flow: submit → abandon hosted checkout → change cart (autosave releases reservation, clears session id) → re-submit → pay. | Fold the frozen total (or a per-submit nonce persisted on the order) into the key, e.g. `checkout-${orderId}-${amountCents}`, so same-total retries collapse but a re-frozen total mints a fresh session. Map the Stripe 400 to a clean retryable error instead of a 500. |
| SR-03 | minor | `README.md:1` (title "phase P6"; file ends at line 115) | README is two phases stale against the shipped tree: it documents through P6 only. P7–P12 (package engine, Shippo shipping + margin law, delivery routes + driver links + pickup, seasons/repeat, email platform, reports/exports/legacy imports/reconciliation, and the eight cron schedules in `vercel.json`) have no operator documentation. Violates the workspace workflow rule "Keep README current". | Add "What P7..P12 ship" sections and a cron/env table (env-spec.ts already carries per-key descriptions to lift). |
| SR-04 | minor | `lib/csv.ts:61` (`csvCell`), consumed by `lib/exports/datasets.ts` | Export CSVs are not formula-injection safe. Cells are quote-escaped but leading `=`, `+`, `-`, `@` (and tab) pass through raw; recipient/customer names and emails are user-controlled at checkout, and staff open these exports in Excel. | At the export edge, prefix any text cell starting with `= + - @` or tab with `'`. Keep `lib/csv.ts` generic; sanitize in `datasets.ts` row mapping. |
| SR-05 | minor | `middleware.ts:14` vs `lib/env.ts:37-38` | The middleware recomputes its own dev-login redirect predicate (`DEV_AUTH_BYPASS === "true" && VERCEL_ENV !== "production"`) instead of sharing `isDevAuthBypass`, which additionally requires `APP_ENV === "test"` and excludes preview deploys. On a misconfigured preview deploy (`DEV_AUTH_BYPASS=true` leaked), unauthenticated admin visitors redirect to a `/dev-login` that correctly 404s — confusing, not exploitable (no session can be minted). | Single-source the predicate: middleware reads the same three env vars through one shared helper instead of duplicating a subset. |
| SR-06 | minor | `app/(storefront)/page.tsx:46-56` | Homepage impact stats overstate reality. "Packages delivered" counts every Package row ever materialized (all seasons, any stage — including NEW/unpacked), and "Families served" counts every Customer row including guests with abandoned drafts. | Relabel ("Packages packed", "Families reached") or filter: terminal-stage packages / customers with a FINALIZED order. |
| SR-07 | minor | `lib/orders/drafts.ts:129` (`saveDraft`) + `app/api/drafts/route.ts` | Draft saves are last-write-wins with no concurrency check, although `Order.version` exists, increments on every save, and is returned to the client. Two tabs/devices (or a POS session plus the customer's own tab) editing the same draft silently clobber each other's lines. | Accept a `baseVersion` in the save body and 409 on mismatch, or document the single-editor assumption where POS/staff share drafts. |
| SR-08 | minor | `.gitignore` (workspace root) + `lib/media/storage.ts:15` | `.uploads/` is not gitignored, so local-driver media bytes (user-uploaded product photos, wizard copies) are committable — they currently sit as untracked files in this tree. `.pgdata/` and `.scratch/` are ignored; `.uploads/` is the same class of local runtime artifact. | Add `.uploads/` to the workspace `.gitignore`. |
| SR-09 | minor | `next.config.mjs` (whole file) | No security headers are set anywhere: no `X-Frame-Options`/CSP `frame-ancestors`, `X-Content-Type-Options`, or `Referrer-Policy`. Admin and account pages are clickjacking-exposed and MIME-sniffing is open. | Add a `headers()` block in `next.config.mjs` with at least `X-Frame-Options: DENY` (or CSP `frame-ancestors 'none'`), `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`. |
